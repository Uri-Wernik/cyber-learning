# Segurança ofensiva autorizada na nuvem

<div class="book-intro" markdown>

Este livro acompanha uma jornada de aprendizagem em cibersegurança desde os fundamentos. A primeira edição explica como a infraestrutura de nuvem funciona, como preparar um laboratório controlado e como interpretar técnicas ofensivas dentro de limites éticos e legais.

!!! warning "Uso autorizado"

    Os procedimentos descritos destinam-se exclusivamente a sistemas próprios, CTFs, laboratórios isolados ou ambientes cobertos por autorização explícita. Conhecer uma técnica não concede permissão para aplicá-la contra terceiros.
